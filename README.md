# FinderPlus（访达平替）

原生 Swift / SwiftUI 的 macOS 文件管理器。要求 macOS 14 及以上，Apple 芯片。

## 一、用 GitHub 编译（约 5 分钟）

1. 在 GitHub 新建仓库（私有也行）。
2. 把本文件夹里的**所有内容**上传到仓库根目录（注意包含隐藏的 `.github` 文件夹；用 `git push` 最稳妥）：
   ```bash
   cd FinderPlus
   git init && git add -A && git commit -m "init"
   git branch -M main
   git remote add origin 你的仓库地址
   git push -u origin main
   ```
3. 打开仓库的 **Actions** 页面，会看到 “Build FinderPlus” 自动开始运行，几分钟后完成。
4. 点进这次运行，在页面底部 **Artifacts** 下载 `FinderPlus`，解压得到 `FinderPlus.zip`，再解压得到 `FinderPlus.app`。
5. 因为没有苹果开发者签名，首次打开需要在终端执行一次：
   ```bash
   xattr -cr /你放置的路径/FinderPlus.app
   ```
   然后再双击打开（或右键 → 打开）。

**编译失败怎么办**：点开红色的步骤，把报错原文复制给我，我来改。
**测试**：核心逻辑自检（复制/移动/废纸篓/搜索/批量重命名等）在编译之后运行，失败只会标黄提醒，不会阻止你拿到 App；日志在 Artifacts 的 `test-log` 里。

## 二、权限

- 首次进入桌面、文稿、下载等文件夹，系统会弹出授权，点“允许”。
- 想浏览整个硬盘：**系统设置 → 隐私与安全性 → 完全磁盘访问权限**，添加 FinderPlus，然后重新打开。
- 每次用新编译的版本替换旧版本，系统可能会重新要求授权（因为是临时签名）。

## 四、使用提示

- **剪贴板历史**（左侧栏下方）：自动记录你复制的文字、图片、文件，最多 60 条。点一条就放回剪贴板；右键可以固定、删除、把文件条目粘贴到当前文件夹、把文字条目存成文本文件。
  - 隐私：密码管理器标记为“机密”的内容不会记录；右上角开关可暂停记录，垃圾桶清空（已固定的保留）。
  - 文字和文件路径会保存在本机 `~/Library/Application Support/FinderPlus/clipboard-history.json`，图片只保留在本次运行中，不写入磁盘。

- **剪切**：⌘X 后到目标位置 ⌘V，才会真正移动（访达没有的功能）。
- **拖拽**：默认移动（同一磁盘）或复制（跨磁盘），按住 ⌥ 强制复制。可拖到侧栏收藏夹、标签页上。
- **选中信息**：选一个文件看详情和预览；多选在右侧面板和底部状态栏显示总大小、数量、类型分布。选中文件夹会自动统计它的大小。
- **找空间杀手**：工具栏 `#` 按钮显示所有文件夹大小，点“大小”列头排序；或用“空间分析”按大小占比列出当前文件夹的子项。
- **图标大小**：图标模式下，底部状态栏有滑块；查看菜单里有 超大/大/中/小 四档。

## 五、已知限制

- 从软件里把**多个选中文件一次性拖到其他应用**时，只会带出鼠标按住的那一个（软件内部拖拽多选没问题）。
- 图标视图暂不支持“框选”，用 ⌘ / ⇧ 点选，或 ⌘A 全选。
- 没有分组（按类型/日期分组）功能。
- 剪贴板历史记录的是系统剪贴板的变化，只能记录从这个软件启动之后复制的内容。
- 访达的 iCloud 状态、AirDrop、标签颜色、“服务”菜单等系统级功能无法实现。
